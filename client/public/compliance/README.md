# Compliance Assets

This directory contains compliance and regulatory certification assets for Funds Consolidation Inc.

## Assets Included

- `trust-badges.png` - Trust and compliance badges display
- `emi-license.png` - EMI (Electronic Money Institution) License Certificate
- `fca-certificate.png` - FCA (Financial Conduct Authority) Regulation Certificate
- `gdpr-compliance.png` - GDPR Compliance Certificate

## Usage

These assets should be used in:
- Landing pages
- Trust/compliance sections
- Footer certifications
- About/credentials pages
